# Pigeon Union

> Manage a city where pigeons strike over bread wages.

A cozy management game where you run a city plaza by keeping pigeon unions happy and preventing bread-price inflation. Pigeons have contracts, dental plans, and opinions about coop safety, so every strike is a negotiation with feathers. The twist is that one overworked pigeon can unionize the seagulls and start a waterfront crisis.

## Features
- Hire pigeons with skill cards like seed-cracking, dramatic landing, and loaf-lobbying.
- Negotiate contracts using bread, crumb tokens, coop rent, and dental coverage.
- Resolve strikes triggered by cats, wind, mayoral photo ops, or union seagulls.
- Track plaza reputation and tourist income while keeping the flock from forming a committee.

## Stack
- Phaser
- TypeScript
- Zustand
- Howler

## Getting started
```
npm install && npm run dev
```
